Pill button — the primary action control. `primary` carries the Sunset gradient and is the only gradient allowed besides the sidebar.

```jsx
<Button variant="primary" icon="plus">Add Campaign</Button>
<Button variant="secondary" icon="filter">Filter</Button>
<Button variant="ghost">Play</Button> {/* on Sunset only */}
```

- Sentence/title case labels, imperative verbs ("New member", "Remove Member"). Never ALL CAPS.
- Hover: primary lifts 1px + deeper orange glow; secondary fills cream #FFF5F0 with coral border. Press: scale 0.98.
