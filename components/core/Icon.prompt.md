Inline stroke icon (Lucide/Feather style, 2px, round caps) — use for every glyph in JuicySuite UI; inherits `currentColor`.

```jsx
<Icon name="users" size={20} style={{ color: "var(--accent-secondary)" }} />
```

- Sizes: 12 (text links) · 14 (secondary buttons) · 16 (primary CTA) · 18 (sidebar nav) · 20 (KPI circle).
- Never substitute emoji for icons.
