Organic marketing silhouettes traced from the 2026 poster references — use for field compositions, frame-break posters and knockout stacks; never in product UI.

```jsx
<Blob shape="slab" width="88%" height="88%" gradient="grape" style={{ position: "absolute", left: "4%", top: "9%" }} />
<Blob shape="squircle" width="95%" height="46%" style={{ position: "absolute", left: "2.5%", top: "2.6%" }} />
```

- Shapes: `bloom` (field blob), `sweep` (corner-bleed arc, full-bleed box), `slab` / `slabTilt` (frame-break), `squircle` / `cushion` / `pebble` (knockout stack).
- Gradients: `sunsetFlat` (90° orange→pink), `grape` (green→violet), `blush` (pink→teal), `meadowSweep` (yellow→teal).
- Paths stretch to width × height, so set both for poster layouts.
