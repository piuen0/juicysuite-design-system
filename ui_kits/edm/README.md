# EDM UI kit — Daily Report email

`index.html` is the source daily merchant report email, verbatim (720px, table layout, inline styles, Arial for email-client safety). Use it as the template for any JuicySuite EDM — and for documents (quotations, proposals, documentation), which share the same cream surfaces, pill stats, split bars and text wordmark.

Patterns (also available as React components in `components/edm/` for previews): cream surfaces (#F5F3EE page, #FFFDF6 card, #FCFBF7 rows), 30–32px radii, text wordmark "Juicy**suite**", light 300-weight display numerals with -2/-3px tracking, pill stat rows with 135° gradients, split pill bars with 90° gradients, half-pill composition header, #FF8C42 solid pill CTA.
